# 会话

Pi 将对话保存为会话,让你可以继续未完的工作、从更早的轮次分叉、并回访之前的路径。

## 会话存储

会话自动保存到 `~/.pi/agent/sessions/`,按工作目录组织。每个会话是一个具有树状结构的 JSONL 文件。

```bash
pi -c                  # 继续最近一次会话
pi -r                  # 浏览并选择历史会话
pi --no-session        # 临时模式;不保存
pi --name "我的任务"    # 启动时设置会话显示名称
pi --session <路径|id>  # 使用指定的会话文件或部分会话 ID
pi --fork <路径|id>    # 把会话文件或部分会话 ID 分叉为新会话
```

在交互模式中使用 `/session` 可以查看当前会话文件、会话 ID、消息数、token 和费用。

JSONL 文件格式与 SessionManager API 见[会话格式](session-format.md)。

## 会话命令

| 命令 | 说明 |
|---------|-------------|
| `/resume` | 浏览并选择历史会话 |
| `/new` | 开始新会话 |
| `/name <名称>` | 设置当前会话显示名称 |
| `/session` | 显示会话信息 |
| `/tree` | 导航当前会话树 |
| `/fork` | 从之前的用户消息创建新会话 |
| `/clone` | 把当前活跃分支复制为新会话 |
| `/compact [提示]` | 摘要较旧的上下文;见[压缩](compaction.md) |
| `/export [文件]` | 把会话导出为 HTML |
| `/share` | 上传为私有 GitHub gist 并附带可分享的 HTML 链接 |

## 恢复与删除会话

`/resume` 为当前项目打开交互式会话选择器。`pi -r` 在启动时打开同一选择器。

在选择器中可以:

- 输入文字搜索
- Ctrl+P 切换路径显示
- Ctrl+S 切换排序方式
- Ctrl+N 只显示命名会话
- Ctrl+R 重命名
- Ctrl+D 删除,然后确认

可用时,pi 使用 `trash` CLI 执行删除,而不是永久移除文件。

## 会话命名

使用 `/name <名称>` 设置人类可读的会话名称:

```text
/name 重构认证模块
```

启动时用 `--name` 或 `-n` 设置名称:

```bash
pi --name "重构认证模块"
pi --name "CI 审计" -p "审一下这个构建失败"
```

命名会话在 `/resume` 和 `pi -r` 中更容易找到。

## 用 `/tree` 分支

会话以树的形式存储。每个条目都有 `id` 和 `parentId`,当前位置就是活跃叶子。`/tree` 让你跳转到任意历史节点并从那里继续,而无需创建新文件。

<p align="center"><img src="images/tree-view.png" alt="树状视图" width="600"></p>

树形示例:

```text
├─ user: "你好,能帮我..."
│  └─ assistant: "当然!我可以..."
│     ├─ user: "我们试试方案 A..."
│     │  └─ assistant: "对于方案 A..."
│     │     └─ user: "成功了..."  ← 活跃
│     └─ user: "其实,方案 B..."
│        └─ assistant: "对于方案 B..."
```

### 树状视图按键

| 按键 | 动作 |
|-----|--------|
| ↑/↓ | 在可见条目间导航 |
| ←/→ | 上/下翻页 |
| Ctrl+←/Ctrl+→ 或 Alt+←/Alt+→ | 折叠/展开,或在分支段之间跳转 |
| Shift+L | 为选中条目设置或清除标签 |
| Shift+T | 切换标签时间戳 |
| Enter | 选中条目 |
| Escape/Ctrl+C | 取消 |
| Ctrl+O | 循环切换过滤模式 |

过滤模式有:default、no-tools、user-only、labeled-only 和 all。在[设置](settings.md)中用 `treeFilterMode` 配置默认值。

### 选中行为

选中用户或自定义消息时:

1. 叶子移动到所选消息的父节点。
2. 所选消息文本进入编辑器。
3. 你可以编辑后重新提交,从而创建新分支。

选中 assistant、tool、compaction 或其他非用户条目时:

1. 叶子移动到该条目。
2. 编辑器保持为空。
3. 你可以从该节点继续。

选中根用户消息会把叶子重置为空对话,并把最初的提示放回编辑器。

## `/tree`、`/fork` 与 `/clone`

| 特性 | `/tree` | `/fork` | `/clone` |
|---------|---------|---------|----------|
| 输出 | 同一会话文件 | 新会话文件 | 新会话文件 |
| 视图 | 完整树 | 用户消息选择器 | 当前活跃分支 |
| 典型用途 | 就地探索不同路线 | 从更早的提示开始新会话 | 继续之前复制当前工作 |
| 摘要 | 可选的分支摘要 | 无 | 无 |

想保留各条备选路线时用 `/tree`;想要独立的会话文件时用 `/fork` 或 `/clone`。

## 分支摘要

当 `/tree` 从一个分支切到另一个分支时,pi 可以摘要被放弃的分支,并把摘要附加到新位置。这样无需回放整个分支,就能保留你离开的那条路径的重要上下文。

收到提示时,三选一:

1. 不摘要
2. 用默认提示摘要
3. 用自定义关注点指令摘要

分支摘要的内部机制和扩展钩子见[压缩](compaction.md)。

## 会话格式

会话文件是 JSONL,包含消息条目、模型切换、思考等级切换、标签、压缩、分支摘要和扩展条目。

解析器、扩展、SDK 用法以及完整的 SessionManager API 见[会话格式](session-format.md)。
